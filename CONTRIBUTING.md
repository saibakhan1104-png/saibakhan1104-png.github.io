# Contributing / Updating This Portfolio

This repository is primarily a personal learning portfolio.

When adding a new chapter:

1. Create a chapter folder using the format `chXX-topic-name`.
2. Add a `README.md` explaining the concepts in your own words.
3. Put Java source files inside `src/`.
4. Add a short description for each program.
5. Test the program before committing.
6. Update the progress table in the root `README.md`.

Keep examples small, readable, and focused on the concept being learned.
