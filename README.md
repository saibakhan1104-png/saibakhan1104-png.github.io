## ▶️ How to Run

### 1. Install Java

Check whether Java is installed:

```bash
java -version
javac -version
```

### 2. Clone the repository

```bash
git clone https://github.com/saibakhan1104-png/java-learning-portfolio.git
cd java-learning-portfolio
```

### 3. Run a program

For example:

```bash
cd ch01-02-intro-and-elementary-programming/src
javac HelloWorld.java
java HelloWorld
```

### 4. Run the calculator

```bash
cd ch01-02-intro-and-elementary-programming/src
javac SimpleCalculator.java
java SimpleCalculator
```

### 5. Run the command-line example

```bash
javac CommandLine.java
java CommandLine 4.5 7.9
```
